# 월간 리포트

## 1. 목적

이번 달이 어땠는지 한 화면에서 본다. 개별 거래가 아니라 **패턴**을 보는 자리다.
"식비가 늘었나", "예산 안에 있나", "지난달과 뭐가 달랐나"에 답한다.

## 2. 라우트와 데이터

| | |
|---|---|
| 경로 | `/reports/{period}` — `period`는 `YYYY-MM` |
| 부르는 곳 | `api` — `GET /v1/summary`, `GET /v1/budgets/status` |
| 기본 | `period`가 없으면 이번 달 |

**집계는 전부 `api`가 계산해서 내려준다.** 거래 목록을 받아 화면에서 더하지 않는다.
LLM에게 산수를 시키지 않는다는 원칙과 같은 이유로, 화면에서도 하지 않는다. 합계가
두 군데서 계산되면 언젠가 두 숫자가 달라진다.

기간 경계는 사용자 타임존 기준이다
([../../docs/development-rules.md 6.1](../../docs/development-rules.md#61-시간--저장은-utc-경계는-사용자-타임존)).

## 3. 화면 구조

| 영역 | 내용 |
|---|---|
| 기간 선택 | `← 2026-09 →`. 다음 달은 오늘이 속한 달까지만 |
| 요약 | 지출 합 · 수입 합. 지난달 대비 증감 |
| 카테고리별 | 표. 이번 달 · 지난 달 · 증감 |
| 예산 | 예산을 정한 카테고리만. 소진율과 페이스 |
| 눈에 띈 것 | 문장 두세 줄 |

카테고리별 표는 이렇게 생겼다.

| 카테고리 | 이번 달 | 지난 달 | 증감 |
|---|---|---|---|
| 식비 | -412,000 | -350,000 | **+62,000 (18%)** |
| 교통 | -88,000 | -92,000 | -4,000 (4%) |

지출이 **늘어난** 것을 강조한다. 줄어든 것은 강조하지 않는다. 이 화면을 여는 사람은
대개 "왜 이렇게 많이 썼지"를 알고 싶어서 온다.

### 3.1 "눈에 띈 것"은 문장으로 낸다

숫자만 늘어놓으면 읽는 사람이 직접 비교해야 한다. 큰 변화 두세 개만 골라 문장으로 낸다.

> 식비가 지난달보다 62,000원 늘었어요. 카페가 그중 31,000원입니다.
> 교통비는 예산의 40%만 썼어요.

이 문장은 **`api`가 만들지 않고 `ui`가 만들지도 않는다.** 문장 생성은 에이전트 일이다.
지금은 규칙 기반 문구로 시작하고, 에이전트 요약을 붙이는 건 나중에 정한다.

## 4. 상호작용

| 무엇을 | 무엇이 갱신되나 |
|---|---|
| 기간 이동 | 페이지 전체. URL도 바뀐다 |
| 카테고리 행 클릭 | [거래 목록](transactions.md)으로. 기간·카테고리 필터가 걸린 채 |
| "왜 늘었는지 물어보기" | [채팅](chat.md)으로. 질문이 입력창에 채워진 채 열린다 |

마지막 줄이 두 경로를 잇는 자리다. 리포트는 *무엇이* 달라졌는지까지 보여주고,
*왜*는 대화가 답한다. 리포트에 설명을 욱여넣지 않는다.

## 5. 빈 상태·로딩·에러

| 상황 | 화면 |
|---|---|
| 이번 달 거래가 없다 | "이번 달 기록이 아직 없어요" + 입력 버튼 둘 |
| 첫 달이라 비교 대상이 없다 | 지난 달 열과 증감 열을 **숨긴다**. 0원으로 채우지 않는다 |
| 예산을 하나도 안 정했다 | 예산 영역 자리에 "[예산 정하기](budgets.md)" 한 줄 |

증감 열에 `-100%`가 뜨는 화면은 첫 달 사용자에게 아무 의미가 없다. 열을 없애는 게 낫다.

**로딩** — 영역별로 따로 채운다. 예산 호출이 느리다고 요약까지 기다리게 하지 않는다.

## 6. 결정과 이유

- **차트를 넣지 않는다.** 표와 숫자로 먼저 만든다. 카테고리가 열 개 남짓인 화면에서
  파이 차트는 표보다 읽기 어렵다. 필요하면 써 보고 정한다.
- **순액을 크게 내지 않는다.** 월급이 들어온 달은 언제나 플러스라 의미가 없다.
- **증감은 금액과 퍼센트를 같이 낸다.** 1,000원에서 2,000원이 된 것도 100%다.

## 7. 하지 않는 것

- 주간·연간 리포트. 월 단위로 시작한다.
- 임의 기간 선택.
- 리포트 내보내기·공유.
